```  mermaid
sequenceDiagram
    participant Frontend as Frontend (Next.js)
    participant API as Backend API (Go)
    participant SSE as SSE Handler (Go)
    participant Manager as ReactionStreamManager
    participant OtherUser as 他のユーザー

    Note over Frontend,Manager: 1. 認証フェーズ
    Frontend->>API: POST /api/login
    API-->>Frontend: JWT + refresh token (Cookie)

    Note over Frontend,Manager: 2. SSEトークン生成
    Frontend->>API: POST /api/sse/token (Authorization: Bearer JWT)
    API-->>Frontend: SSE token (60秒有効)

    Note over Frontend,Manager: 3. SSE接続確立
    Frontend->>SSE: GET /api/reactions/events?token=sse_token
    SSE->>SSE: トークン検証 & ユーザーID抽出
    SSE->>Manager: Subscribe(userID)
    Manager->>Manager: channel作成/取得
    Manager-->>SSE: receive-only channel
    SSE-->>Frontend: SSE connection open
    SSE-->>Frontend: keepalive

    Note over Frontend,Manager: 4. リアクション発生時
    OtherUser->>API: POST /api/reactions
    API->>API: 投稿者ID取得
    API->>Manager: BroadcastReaction(event)
    Manager->>SSE: channel <- event
    SSE-->>Frontend: SSE data event
    Frontend->>Frontend: アバターに表情を表示

    Note over Frontend,Manager: 5. 再接続
    Frontend->>Frontend: 55秒後タイマー
    Frontend->>Frontend: SSE切断
    Frontend->>API: POST /api/sse/token
    API-->>Frontend: 新SSE token
    Frontend->>SSE: 再接続
```

基本的にはアクセストークンを15分間発行。
リフレッシュトークンは1ヶ月間有効であり、リフレッシュトークンを用いてアクセストークンを作成。
他の人からdmが飛んできた場合のみSSEで通信を行い更新を行う。
SSEトークンは基本的に短く設定。
SSEトークンはクエリに含めるしかないのでセキュリティ的に弱く、超短期間トークンとする。
